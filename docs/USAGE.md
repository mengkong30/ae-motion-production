# 详细使用指南

使用前请阅读 [免责声明](../DISCLAIMER.md)，并备份需要修改的工程。

## 1. 任务开始前准备什么

| 信息 | 建议写法 |
| --- | --- |
| 目标 | 新建角色动画 / 临摹参考 / 精修已有工程 |
| 素材 | 提供能读取的视频、SVG、AI 或 AEP 路径 |
| 参考重点 | 指明要学习的节奏、弹性、形状或光效 |
| 保留项 | 角色比例、颜色、已经确认的动作、原工程中的手工调整 |
| 时间规格 | 时长、帧率、是否无缝循环；不确定时让代理根据参考决定 |
| 画面规格 | 尺寸、透明或实色背景、使用场景 |
| 软件环境 | AE 版本、可用软件及脚本/桌面操作能力 |
| 交付 | AEP、SVG、MP4、GIF、透明 WebP 或约定的其他格式 |

示例路径请换成自己的实际路径。不要只给一张截图却要求代理声称已匹配完整参考视频的节奏。

## 2. 制作流程

1. **阅读参考。** 播放视频，检查起点、蓄力、主动作、极值、回弹与末尾。
2. **确认结构。** 按运动关系分件，确定锚点、连接处、前后遮挡和透明孔洞。
3. **建立控制。** 把动作参数放在有职责的控制器上；让路径和子层响应这些参数。
4. **验证代表动作。** 先完成少量能暴露问题的动作，观察连续播放和极值画面。
5. **扩展与精修。** 为各表情安排不同节奏，补充五官、手脚、柔软末端和点缀的配合。
6. **检查工程。** 核对命名、控制器响应、表达式、依赖和素材边界。
7. **输出预览。** 先保存，再分批渲染、编码和检查，最后整理交付包。

这些是制作顺序，不要求每一步都等待用户审批。真正影响方向的选择再沟通；已经获得授权的制作和验证可以继续。

## 3. 可以直接复制的任务模板

### A. 新建角色循环动画

```text
使用 $ae-motion-production。
素材：[角色 SVG / AI 路径]
参考：[参考视频路径]
目标：制作开心、好奇、惊讶和舞动四种循环动画。
造型要求：保留原有比例、颜色和卷毛弧度。
动作要求：有预备、发力与回弹，各部位协调；不同情绪有不同动作节奏。
规格：600×600、30 fps、约4秒循环；可以根据参考调整动作时长。
交付：可编辑 AEP、独立 MP4、透明动图、控件说明。
先完成代表性试片并自行检查，再扩展全套。
```

上面的尺寸、帧率和时长仅为示例，不是技能固定要求。

### B. 修改“整张图摇摆”的角色

```text
使用 $ae-motion-production 精修现有工程：[AEP 路径]。
目前人物像一张图片在摇摆，请检查各部位相对姿态是否真的改变。
身体增加压缩、伸展与弯曲，五官按动作适度跟随，卷毛延迟回弹，
手脚独立发力。保留原来的角色轮廓、颜色和已确认的表情。
另存新版，检查卷毛连接、眼白遮挡、嘴型、脚底接触和循环接缝。
```

### C. 道具开合与光效

```text
使用 $ae-motion-production，按参考制作宝箱打开动画。
先核对箱体、箱盖、内腔、锁扣和铰链关系。
动作顺序为点击反馈、蓄力、开盖、回弹、光效消散。
把箱盖开合关键帧放在有效控制器上；光从开口出现并受箱体遮挡。
交付中文命名的原生可编辑工程与预览。
```

### D. 只加强某一段

```text
使用 $ae-motion-production，在这个已确认工程上另存修改版：[路径]。
只加强结果出现后的回弹和星光流动，保留前面的速度、停点和造型。
光效不要遮住主体，检查光效消失后位置与大小回到正常状态。
```

### E. 批量渲染恢复

```text
使用 $ae-motion-production，检查这次批量渲染的日志与已保存工程：[路径]。
先确认哪些合成实际完成、相关进程是否还在运行。
保留已完成输出，从失败阶段恢复，不重复生成角色或叠加控制器。
如果组合渲染重复失败，可以用完成的独立视频汇总展示，
但必须保留原生可编辑角色，并说明预览与工程的区别。
```

### F. 用户明确需要前端体验时

```text
使用 $ae-motion-production，把这个已确认 AE 动效还原成可点击的网页体验。
沿用实际矢量素材与控制器时间线，不靠猜测重新画一套近似动画。
检查触发、播放中、结果、重置和重复操作，兼顾手机与键盘输入。
先完成本地验证；本任务只做本地交付，不发布线上。
```

## 4. 在 AE 中如何接手修改

1. 打开交付的 AEP，进入目标角色或道具的独立合成。
2. 选择中文命名的控制器，按 **U** 展开带关键帧的属性。
3. 在效果控件中调节幅度，或移动关键帧改变时间。
4. 预览变化，确认子层一起响应。需要修改造型时再进入对应形状路径。
5. 修改后检查起点、中间、极值、终点以及循环两端。

不同角色的控件名称会不同，常见组织方式如下：

| 控制器 | 常见参数 |
| --- | --- |
| 整体 | 位置、整体角度、相对大小 |
| 弹性身体 | 压缩拉伸、上身弯曲、卷毛摆动 |
| 表情 | 视线、眨眼、眉毛、张嘴、嘴型宽度 |
| 手势 | 左右手位移、摆角、抬脚 |
| 点缀 | 爱心、泪滴、音符的进度和强调强度 |

以实际交付说明为准。跟随动作应读同一个时间源，移动主动作后不应需要逐层重新对齐。

## 5. 如何判断是否合格

- **造型：** 弧度、尖端、孔洞和色块边界贴合，极值时不折叠、不露缝。
- **动作：** 有清楚的发力方向和先后关系；没有无意停顿、脚底滑动或所有部位同步僵摇。
- **遮挡：** 瞳孔不穿出眼白，舌头不穿出口腔，光效不覆盖关键造型。
- **循环：** 首尾姿态和速度相接，粒子换圈没有突跳。
- **可编辑性：** 控制器真实生效，图层及参数有意义，源文件依赖清楚。
- **输出：** 实际视频可播放，帧率与时长正确，透明素材在深色背景下没有白边。

连续播放与接触表配合检查；技术统计用于辅助定位，不能替代视觉判断。

## 6. 常见问题

### 找不到技能

确认复制的是含 `SKILL.md` 的完整 `ae-motion-production` 文件夹，检查当前环境实际扫描的位置。必要时重启 Codex。不要把文件夹多套一层，也不要在多个位置安装同名副本。

### 装了技能却不能操作 AE

技能提供工作方法，不提供 AE 本身或桌面控制连接。先确认当前机器安装的软件、脚本执行能力、文件读写权限和可用控制工具。缺少能力时，应明确已完成与未验证的部分。

### 关键帧很多，但人物仍然僵硬

检查轮廓是否只跟着整体层旋转，手脚与五官是否始终保持相对姿态。先修身体的发力和局部动作，再加光效；不要只增加关键帧数量。

### 变形时卷毛或腹部出现接缝

核对共同坐标映射、贝塞尔切线、分件连接点和动态遮罩。加点可能提高变形精度，也会提高计算成本，应从代表路径验证。

### 状态一直显示“渲染中”

检查本次对应进程、退出码、日志及输出更新时间。命令退出后留下的旧状态不是仍在工作的证据。不要反复启动新实例或无依据结束用户进程。

### 单个角色成功，但总览失败

把组合负载与单个负载分开排查。可以有限尝试独立渲染等恢复方式；失败仍持续时，保留原生角色，用已完成的独立成片生成展示总览。说明哪些预览被停用，不删除原内容来掩盖问题。

### 透明动图边缘发白

确认读取了真实 alpha，检查直通/预乘与底色。只有确定是预乘时才去预乘，再放在深色背景检查。更详细的公式和 PyAV 注意事项见[角色柔性动效文档](../skills/ae-motion-production/references/character-motion.md)。

## 7. 更新技能

下载新 Release，比较本地修改后更新技能目录。保留完整的 `references/` 和 `agents/`；不要只替换入口文件而留下不一致的参考版本。

本技能中的软件版本经验和具体案例值，应在新任务中重新验证适用性。新增经验时优先记录影响判断的方法与真实失败条件，不把一次成功或失败推成通用结论。
